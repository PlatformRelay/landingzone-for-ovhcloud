# T008 / T009 — Dependency and changed-closure checks (dependency half)

Status: dependency half GREEN locally, 2026-10-04; static half (pinned `tofu fmt`,
`tofu validate`, tflint) not started. Requirements: FR-007 (C007.4–C007.6). ADRs: 0002,
0008, 0011. T008 and T009 stay open until both halves are done.

## What exists

- `tests/check/fixtures/dependencies/valid/` — a fixture repository with every class ADR-0002
  names: a nested subdirectory (`modules/net/sub`), an alias spelling of the same directory
  (`./../../naming/`), a module example, a component with two external sources (a registry
  module and another repository's subdirectory), a stage that uses this repository's own
  `modules/naming` as a released package (`git::…/ovh-landing-zone-accelerator.git//modules/naming?ref=…`,
  mapped back to the local directory), and a Terramate-generated instance whose generator
  configuration is inherited from `*.tm.hcl` files in its own and ancestor directories.
- `tools/internal/checks/dependencies.go` — `ScanDependencies(root)` parses every `*.tf` with
  `hashicorp/hcl/v2` (vendored, decision D63), reads `module` sources only as literal
  strings, and classifies each directory holding configuration into an ADR-0002 layer
  (library, stage, generated instance, example, test). Rules, each with a control:
  - `LAYER_VIOLATION` — the ADR-0002 edge matrix (see "After the first independent review").
  - `CYCLE`, `UNRESOLVED_REFERENCE` (missing or configuration-less local target, a source
    leaving the repository, a computed or absent source, this repository's address without a
    `//<dir>` or with a missing one), `UNCLASSIFIED`, `PARSE_ERROR`, `UNREADABLE` (symlinks
    anywhere, a missing root).
  - Hidden directories and `fixtures` trees are not scanned: fixtures are checker input data,
    not configuration of this repository.
- `SelectChanged(graph, paths)` — each path selects its owning directory (the deepest
  classified prefix, so test files and READMEs belong to their module) and every transitive
  consumer; an inherited `*.tm.hcl` selects the generated directories that inherit it. Shared
  tooling (`tools`, `harness`, `schemas`, `policies`, `pipelines`, `.github`, `Taskfile.yml`,
  `mise.toml`, `.tflint.hcl`) selects the full suite (`SHARED_TOOL`); any path no directory owns —
  an unknown file, a removed module, an orphan `*.tm.hcl`, a path leaving the repository —
  selects the full suite (`UNKNOWN_PATH`), never nothing. Documentation (`docs/`, `specs/`,
  root `*.md`) selects nothing and says so (`DOCS_ONLY`); no paths is `NO_CHANGES`.
- `lz-check deps` scans the repository and exits 1 on any finding; `lz-check select <path>`
  prints `SELECT …`, `SELECT_FULL <reason>` or `SELECT_NONE <reason>` and refuses a broken
  graph. `task test:dependencies` runs the fixture tests and then scans this repository.

No generator is implemented (ADR-0002: generators follow two real examples).

### After the first independent review

Seven majors, each fixed behind a control seen failing first:

- **Edge matrix** — now exactly ADR-0002: `modules/naming` uses nothing; other modules use only
  `modules/naming`; components use modules; stages use components; only generated deployment
  instances use stages; examples and tests use library code (modules, components), never
  stages; only tests use tests; any edge within one package is allowed (cycles still fail).
  The fixture no longer expects `example → stage` or `stage → module`.
- **Layout decides the layer** — a Terramate-generated file inside a library adds that
  directory's inherited `*.tm.hcl` inputs but does not turn it into an instance.
- **Singleton components** (`account-baseline`, `project-factory`, `guardrails`,
  `state-backend`) are packages of their own, with subdirectories inside the package.
- **This repository's address** is normalised (forced getter, scheme, user, scp-style host,
  `.git`, letter case), so `git::ssh://git@github.com/PlatformRelay/…` resolves like the https
  form; any other mention of the repository that is not a resolvable `//<dir>` address is
  `UNRESOLVED_REFERENCE`.
- **Test configuration** — `module` sources in `*.tftest.hcl` run blocks are parsed and resolved
  against the module root; they are recorded as `TestUses`, and a change to the used module
  selects the module whose tests run it.
- **JSON configuration** (`*.tf.json`, `*.tftest.json`) is refused as `UNSUPPORTED_CONFIG` rather
  than skipped.
- **Documentation** means Markdown at the root or under `docs/` and `specs/`; any other file
  there (`docs/check.sh`) widens to the full suite.

An unreadable configuration or test file is reported as `UNREADABLE`.

## Limits

- Directory type comes from layout and the Terramate header; a generated file without the
  header is not recognised as generated.
- `select` takes one path through the entry (the entry admits one argument); the `task check`
  aggregate that combines selection with running checks is still to come (T009 static half /
  T021).
- Remote sources other than this repository are recorded, not resolved; their own changes are
  outside this repository's selection by design.
