## Task text (tasks.md)

T024 Write snapshot-admission tests for generated stacks in tools/cmd/lz-offline/ tests and fixtures. Requirements: FR-001, FR-002; ADRs: 0002, 0008, 0011, 0021. Depends on: T003. Verify: `go -C tools test ./cmd/lz-offline -count=1`: a candidate holding `stacks/` (generated stacks, `stacks/deployments.yaml`, `stacks/_lz/*.tm.hcl`) and a root `terramate.tm.hcl` is snapshotted with those paths present; a hostile file under `stacks/` stays data with no effect on the entry's own targets; a root file outside the allowlist stays absent; symlink, size and depth limits apply under `stacks/` as elsewhere. The current entry omits `stacks/` and `terramate.tm.hcl`: behavioural red. Found 2026-10-06: without this no offline check sees the stacks spec 005 generates (005/T038).

## Design choices
- **Fixture as JSON, not as a file tree.** A literal tree with `stack {}` blocks and `*.tf` files anywhere in the repository would become a Terramate stack of the project (the root `terramate.tm.hcl` makes the whole checkout one project) and a `test:slice` member. The fixture is `path → content`; the test materialises it in a temp dir.
- **"Stays data" read as**: copied verbatim below `stacks/` and nowhere else; the snapshot outside `stacks/` is byte-identical with and without the hostile files; the snapshot's exclusions (`.env*`, `.envrc`, `.git`, `.terraform`, `.cache`, `.local`) apply below `stacks/` too. The executable bit is preserved as for every other path (T003's behaviour, not changed here).
- **"No effect on the entry's own targets"**: candidate targets run `/tcb/task --taskfile /candidate/Taskfile.yml`, so an unchanged root `Taskfile.yml` is what the unit test can pin (differential test). Trusted targets (`verify:toolchain`, `test:offline-boundary`) never snapshot; pinned by reading and an entry run (row 2a).

## Learnings

Class: sensor, guidance.
- A rejection case must point its link at an admissible target the test controls (a temp dir/file); a link to host state (`/etc`, `/etc/passwd`) can be refused for another reason and hide a following mutant (round 1–2).
- A total-budget mutant must remove the clause itself (stop counting), not only one check site: with a later allowlisted file the remaining-budget check refused anyway.
- A differential "no effect outside X" test compares every entry's type and mode, not regular-file content only.
- `./cmd/lz-offline`'s tests run under no Task target: any entry test task must say who wires it into CI (here T025, decision 1).
