## Learnings

Class: tooling, guidance.
- A generic script name in the shared records directory (`t021-leg1.sh`) may already belong to another spec: writing it failed, and running the old one overwrote spec 007's T021 leg record (its review leg 1 output in `loop-007/reviews/L-tasks/T021/`, now empty). Prefix scripts with the spec (`s004-t021-…`) and stop on a Write that says the file exists.
- A how-to that restates the command's consequence notes restates OVHcloud claims: cite each note's source or mark it UNVERIFIED.
- Host `mise exec -C <checkout>` refuses an untrusted `mise.toml`; run `mise exec -- task -d <checkout>` from `$HOME`, and tell an operator to `mise trust` first.
