## Choices made here (not fixed by the spec set)

- Signature: `Export(a Answers) ([]byte, error)`; plan.md and data-model fix none. A refusal returns `nil` and the decoder's own `*stacks.ManifestError` unwrapped, so T018 can pick the catalogue source (`generated`) by type and print the decoder's detail.
- Output form: `json.MarshalIndent` (two spaces) of ordered Go structs, plus a final newline; no comment line. Key order is the struct field order of data-model *Derivation* steps 1–3; no map is marshalled. Rows are not one per line as in `stacks/deployments.yaml`; FR-003 and SC-001 ask for value-equality only (verified 2026-10-25, data-model *Value-equality*).
- Header and fixed values come from `stacks.ManifestAPIVersion`, `stacks.ManifestKind`, `stacks.ManifestScopePlatform`; `stage_source.kind` `local`, the default state ref `STATE` and the default mode `reference` are constants in `export.go`.
- Refused-derivation cases are built in Go from the two-tenant answers with the defect in tenant `lab` (second tenant, lesson T016), then marshalled and passed through `DecodeAnswers`, so each case is an answers file T016's decoder accepts. Their refusals (verified 2026-10-25, scratch probe): `DUPLICATE_VLAN` (`vlan_id 0 of lab/dev/DE1 is also GRA11's`), `SHARED_STATE_PROJECT` (`lab/dev uses the state project STATE …`), `DUPLICATE_NAME` (`project LAB_DEV is owned by lab/dev and lab/prod`), `INVALID_VALUE` (`spec.instances[].id: "lab-dev-aaaa…a1-network" does not match ^[a-z][a-z0-9-]{2,62}$`). The test asserts the unwrapped type, the code and that the detail names `lab` (since `d2a59be`).
- The region-without-cidr and override cases read `all-fields.yaml`, whose shop/prod has `DE1` with `cidr` and `vlan_id` 4000 and `GRA11` without `cidr` at index 1; shop/test omits every override and is checked for the defaults.

## Learnings

Class: guidance.
- Value-equality and byte-equality across runs both miss a key order that is consistently wrong; when a spec fixes key order, assert it separately, on keys (`"k": `), not on bare strings a value can also hold (metadata.name `sandbox`).
- When a later task relies on an error being returned unwrapped (T018 picks the catalogue source by type), pin it with a type assertion, not `errors.As`, which passes on a wrapped error.
- A fixture described as "every optional field off its default" needs checking against derived defaults too (`state_endpoint` equalled the default for its region).
