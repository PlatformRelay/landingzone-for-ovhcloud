## Learnings

Class: tooling.
- A Task variable with `| default` treats an empty value as unset: a failed `$(mktemp -d)` in `VAR="$(…)"` silently falls back to the default; make the temporary path inside the target and stop on its failure.
- Task ignores a variable the target does not use: after renaming a target's variable, a helper script still passing the old name runs the default path (here, an export into the worktree). Grep the records directory for the old name before re-running a helper.
- Task exposes environment variables to templates: test a flag for one exact value, never for non-empty, and never render it into shell text.
- An error message that already holds a path makes a `Contains(path)` assertion on a wrapper vacuous: assert the wrapper's own prefix.
