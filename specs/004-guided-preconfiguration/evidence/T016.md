## Choices made here (not fixed by the spec set)

- `AnswersError{Code, Detail}`: Detail is the field path of a field error (`tenants[0].environments[0].regions[0].cidr`, no `$.`; a type mismatch too, found by walking the document beside the Go types; `(document)` for the top level), `line <n>` of a syntax error, `<n> bytes` when `DecodeAnswers` gets an oversized document, and the file path for `ReadAnswers`' refusals. T018 formats it.
- Case variant: the fixture puts `"Tenants": []` beside `tenants`, so the refusal is `UNKNOWN_FIELD Tenants`. With `Tenants` alone, `checks.DecodeStrict` reports the missing `tenants` first (`MISSING_FIELD`), since it checks required fields before unknown keys (`tools/internal/checks/traceability.go:536-548`, read 2026-10-25).
- `vlan_id` without `cidr`: `INVALID_VALUE` at the `vlan_id` path (data-model: "refused without `cidr`" names no code).
- `checks.DecodeStrict` reports a duplicate key by key alone (`DUPLICATE_KEY: org`), so a path-aware walk (`keyWalker`) runs first; the strict decode still refuses one if the walk misses it.
- `ReadAnswers`: `O_NOFOLLOW|O_NONBLOCK` open, then a regular-file check on the open file (no Lstat/Open race); a missing path, a path under a regular file (`ENOTDIR`), a symlink as the last component, a directory or a FIFO is `ANSWERS_NOT_REGULAR`. A symlinked parent directory is followed: FR-008 names the answers path, and parents are the caller's (T020 resolves the path against `-root`). Other I/O errors (permission) return a plain wrapped error: no catalogue code fits (gap below).
- `test:configure` runs `./internal/configure` only; T020 adds `./cmd/lz-configure` (the package does not exist yet, and `go test` refuses a missing directory).
- `test:configure` is not added to the foundation CI targets: spec 004's checks are not owed to that workflow (`CheckFoundationCI` requires only spec 001's, `tools/internal/checks/foundation_ci.go:325-330`, read 2026-10-25). The workflow, its source and `foundation-runs.json` are untouched.
