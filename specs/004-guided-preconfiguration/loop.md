## Lessons
- Before calling a "registry inputs name path X" clause machine-covered, check whether a parent directory is also listed: `covered()` accepts it (`tools/cmd/lz-check/main_test.go:668-675`). (T015)
- A package importing `tools/internal/checks` depends on `tools/internal/report` (`checks/unit.go:6`): every registry row that runs it lists both, or `TestRegistryInputsCoverGoDeps` goes red. (T016)
- A Taskfile change re-pins `docs/how-to/respond-to-an-incident.md` (it references `Taskfile.yml`); put the pin in the commit that changes the Taskfile, with `last_verified` an earlier commit. (T016)
- Put refusal fixtures at a non-zero index and give a type-mismatch case a valid value of the same field earlier in declaration order, or path mutants that write `[0]` or blame the first such field survive. (T016)
- `json.UnmarshalTypeError.Field` is dotted (`tenants.1.x`) and empty at the top level; `1.0` and `1e0` are type errors for an int but whole floats in a generic decode: locate type errors with `UseNumber`. (T016)
- Importing `tools/internal/stacks` brings `tools/internal/planjson` (`stacks/generate.go`): a registry row whose Go imports `stacks` lists both. (T017)
- Value-equality and repeat-run byte-equality both miss a consistently wrong key order: assert the order on `"key": ` tokens, not bare strings a value can hold. (T017)
- When a later task relies on an error coming back unwrapped, pin it with a type assertion; `errors.As` passes a wrapped one. (T017)
- A completeness check that also refuses stale entries makes its zero-count guard unreachable on the real catalogue: prove the guard with zero codes and an empty catalogue together. (T018)
- A guard with an "a or b" clause (empty sentence or empty action) needs a planted case per side; one case leaves the other clause removable. (T018)
- A comparison by key needs a case that keeps the key and changes the rest of the record, or a whole-record comparison passes. (T019)
- Two triggers proven by one control that sets both cannot be told apart: give each trigger a control that sets it alone. (T019)
- A symlink check followed by path-based writes is a check-then-use race: open each directory as an `os.Root`, check after the open that the name is still that directory (`Lstat`, `os.SameFile`), and write only through the handle. (T020)
- Function-level fixture paths like `../../../tests/…` break a command that resolves a relative path against `-root`: make test fixture paths absolute. (T020)
- The offline entry mounts the candidate read-only, so a target that writes (an export) passes only host-side. (T020)
- Name `.done` markers with the spec as well as the task id: `t020-final.done` from another spec's T020 was already there. (T020)
