## Learnings

Class: sensor.

- A rule with ordered clauses ("(2) lost token → blocked before (3) 404 → not-applicable") needs
  one case per clause that the next clause would otherwise accept: a reference that skipped the
  repeat passed every first-round case. Write the reference and a mutant per clause before review.
- A fake that accepts a required flag only by presence (archive) passes a wrong value: record the
  value and assert it.
