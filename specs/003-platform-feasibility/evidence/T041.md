## Design

- **Kind**: `swift_container`, not a provider type (the provider has no Swift container resource;
  research.md), so it stays out of `matrix` (research R12's provider types, pinned by
  TestLeftoversMatrixKinds) and never meets an inventory. It is listed for every project after the
  networks; a container named Prefix… is a leftover (the run-id match is case-sensitive and the
  container names hold the lower-cased run id, so for the check's containers only the `lzprobe-`
  prefix matches; review r2). The listing runs on
  every run's leftover check, plan-only and the foundation lane included.
- **apicheck.go**: CreateContainer (POST …/storage, body `{"archive":false,"containerName",
  "region"}`), ListContainers (GET …/storage, keeps id and name), DeleteContainer (DELETE
  …/storage/{id}?recursive=true, always recursive), from kb api/v1/cloud.json
  `/cloud/project/{serviceName}/storage` and `…/{containerId}` (cloud.ProjectStorageCreation,
  cloud.storage.Container; actions `publicCloudProject:apiovh:storage/create|get|delete`; read
  2026-10-20). The container id must be one segment of `[A-Za-z0-9+/=._-]` not starting with a
  dot, and is path-escaped (`/` → `%2F`).
- **Observe**: containers created before the seeds; per tenant, after its login: list own, PUT
  `lzprobe-swift-reach/native-<side>`, GET it back, then list the other's container (the
  `swift_native` step); then the six S3-name steps. `judgeStep`: JudgeReach first; a blocked step
  whose control, other and repeat all answered 404 is `not-applicable` with a working control, else
  `blocked` naming the control's failure. Record gains `containers`, `native_control`,
  `swift_native`. A `not-applicable` step passes Observe.
- **Undo/Sweep**: `cleanContainers` with the sandbox admin; Sweep reuses its admin identity and
  prints a separate `removed <n> Swift-native containers` line (the existing line is unchanged).
- Only the cross list step is observed on the Swift-native plane (T040 fixes "at least the list
  steps"); cross read and write are not, so a write ACL gap would go unseen (believed out of scope:
  the decision records the cross steps as observations, not a verdict).
