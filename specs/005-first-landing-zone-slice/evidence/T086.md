## Learnings
- tooling: a tofu validation mutant must still refer to its variable (`<var> != ""`, not `true`): tofu refuses the configuration, no run runs, and a script counting failed runs reads that as a survivor; count passed runs too and report `NO_RUNS`.
- tooling: removing a Go check that defines a variable used only there breaks the build (`want` unused); keep `_ = want` in the mutant so it compiles.
- guidance: count mutants from the plan list, not by memory, before writing the total (codex r1).
- sensor (proposed task line): a `bootstrap` capture case + `planOutputContract(t, msg, "bootstrap", "platform_s3")` so every stage with an output schema has a plan pin.
