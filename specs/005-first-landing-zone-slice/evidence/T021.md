## Learnings
- tooling: `override_resource` takes a keyed instance in a nested module call (`module.a.module.b["k"].type.name`) on tofu 1.13.0, and is silently unused when the instance does not exist; use it to give same-typed resources distinct mock values so a swap is visible.
- guidance: a mutant that drops a keyed element must keep the rest of the throw-away coherent (outputs fall back with `try`), or it dies by `Invalid index` instead of by assertion; the mutant script now accepts multi-file edits.
- guidance: a G6-style resource-union check filters on "not a Deny" in any case, never on `Effect == "Allow"`, so an unknown or differently cased Effect fails closed (review r1).
- guidance: a list output's shape needs `startswith(jsonencode(x), "[")` (a map passes length and for-expressions), and a per-key composition needs an exact per-key set, not a count (review r1).
- sensor (proposal, decision request 1): `lz-check deps` cannot see a stage holding a resource or a second call to its component.
