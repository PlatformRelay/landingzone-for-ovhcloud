## Learnings

- sensor: a clause about the *second* of several runs needs a state that only that run trips over; when an earlier step fails in the red, later steps may pass by accident (here the cleanup passed because run 2's failed in-place init left run 1's backend). Plant the state the clause is about between the steps.
- sensor: judge "outside directory X" on the resolved location the child really used (the fake logs it), not on the variable's text: relative paths and symlinks otherwise pass or fail for the wrong reason; and `strings.HasPrefix(rel, "..")` admits a child named `..x`.
- sensor: a static Taskfile control should anchor the argument (`… unit <dir>$`), or `echo`/comments satisfy it.
- tooling: `t073-reinit.sh` (host tofu backend model), `t073-impl.py` (throw-away for T074), `t073-mutants.py` (28 clause mutants on a scratch with `Taskfile.yml`), `t073-sync.sh`, `t073-gates.sh`.
