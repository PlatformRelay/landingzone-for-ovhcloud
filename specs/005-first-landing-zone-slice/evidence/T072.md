## Learnings

- sensor (class: sensor): a new clause that runs before an existing row's clause can mask that row's mutant — give every fake git dir the full minimal layout a real one has (`objects/`), and rerun the whole mutant set after adding a clause.
- sensor: a "shared repository" guard needs a walk of the object store, not a check of `objects/` alone: a symlinked `pack/` or fan-out directory shares objects without alternates (review round 2).
- sensor: an "equivalent" mutant claim needs a row that exercises the input class it depends on (a relative root that exists from the process's directory, `testdata`), or it is unproven (review round 1).
- tooling: `t072-mutants.py` mutates the committed `guard.go` in a scratch copy with `tools/`, `tests/`, `Taskfile.yml` and runs the pre-task stub as one mutant (`t072-stub.go`).
