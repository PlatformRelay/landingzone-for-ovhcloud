## Learnings
- sensor: a fake server that verifies a signature by recomputing it from the decoded request proves only that the signer is self-consistent; pin the literal wire URI (`RequestURI`) for every encoding class (space, reserved, `%`, non-ASCII), or a `RawPath` regression goes unseen (r1).
- sensor: testing an entry's options builder in isolation does not prove the entry passes what it built; capture the options at the seam the entry uses (`deps.State`) and drive the default far enough that it reads them (r1).
- tooling: the AWS SigV4 vectors live in botocore `tests/unit/auth/aws4_testsuite` (keys in `test_sigv4.py`); docs.aws.amazon.com's S3 sig-v4-header-based-auth page is a JS redirect stub, the docs.aws.eu mirror serves the worked examples as HTML.
