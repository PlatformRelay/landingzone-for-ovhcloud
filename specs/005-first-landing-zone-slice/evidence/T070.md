2. New abstraction — `protectSidecarFaults` returns faults instead of calling `t.Errorf`, so the control can feed it forged sidecars; same shape as the T007 sidecar check, no new package.

8. Docs — script headers, Taskfile comment, the test comments.

## Learnings

Class: sensor.
- A target-existence check must bind what the target runs (its case variable), or swapped cases pass with every digest intact.
- Each clause of a provenance check needs its own negative control; a clause only the positive fixtures exercise survives its mutant.
- A capture driver writes to a temp file and moves it over the fixture only on success, and checks the qualification run's exit separately from grepping its line.
- Moving a host-generated root into a script run by a `capture:<case>` target (case table inside the script, script digest in the sidecar) brings host captures under admission without committing per-case roots.
