## Coordinator decision: route 4 (hidden directories), 2026-10-06

T066's review (Opus) found that `.`-prefixed directories are skipped at any depth, so `modules/a/.scratch/` holding a backend gives no finding. Decision (T067 dispatch): an *unreferenced* hidden directory may stay skipped — OpenTofu never loads a directory no module call names (believed; consistent with module loading by `source` path, not verified against a live run here). A module call whose `source` resolves into a hidden directory must be followed and judged by the purity and layer rules. Implemented: `load` reads exactly the called directory (non-recursive, as OpenTofu loads one module directory), routes its files as the walk does (`.tf` kept; `.tofu`, `.tf.json`, `.tofu.json` refused), refuses a symlink on the way or inside, and the directory is then classified and judged like a walked one; a hidden directory below it is loaded only when a call names it in turn. Applies to `module` blocks, `run { module {} }` blocks in tests, and released self-addresses (`…//modules/a/.impl`). Test files inside a called hidden directory are not read (OpenTofu runs only the root module's tests; believed).

Counterpoint recorded for the coordinator: the skip of an unreferenced hidden directory is now the only place a backend or provider can sit unreported in the tree. It is harmless to OpenTofu but visible to a reader; a narrower alternative (skip only known tool-state names such as `.terraform`, `.terramate`, `.git`) would report it. Not done: the decision says unreferenced hidden directories may stay skipped, and tool-state names are an open list.

## Learnings

- sensor: narrowing a classification rule ("only below a package root") needs controls on *both* sides of every root kind the rule knows — package trees, the root `tests/`/`examples/` trees, and outside both; round 1 missed "outside", round 2 caught the fix breaking "root tree".

- tooling: Python edit scripts must not mention git in a heredoc (guard refuses); write them with the Write tool. A mutant that deletes the only use of an import builds INVALID: neutralise with `&& false` instead.
