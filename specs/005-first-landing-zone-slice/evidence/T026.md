## Learnings
- sensor: a "seen package" registration placed in a per-directory judge misses directories the judge never visits (test-owner-only packages); register from the discovery maps after the walk (review r2).
- sensor: an address count is not an instance count — `for_each` and a subdirectory called twice multiply one address; a single-instance rule must also pin where the block lives and how it repeats (review r1).
- guidance: a tree mutant that replaces "the first occurrence" of an attribute can land in a header comment that quotes it; anchor tree mutants on the attribute line's context.
- guidance: provider "protection" arguments such as `deletion_protection` are provider-side refusals held in state (cloud_project.md), not account settings; a runbook that drops the resource from state drops the protection too.
- tooling: helper names under `~/.local/share/ovh-lz/review/` collide across specs (`t026-*` exists for spec 001); prefix per spec (`t026s5-*`).
