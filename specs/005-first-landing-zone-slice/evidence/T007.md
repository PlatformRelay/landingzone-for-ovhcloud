## Learnings

Class: spec.
- `tofu test` with `mock_provider` crashes (exit 11) on an `import` into a mocked resource, for plan and apply: generated roots with import blocks need a test path without the import.
- Terramate 0.17.3 outside git takes a directory as project root only when its root `terramate` block sets `required_version`. A scratch copy without `.git` needs it.
- `terramate create --tags` sets tags even though its help calls it a filter. `after = ["tag:a:b"]` is AND.
- OpenTofu reports a wrong state passphrase as "Error acquiring the state lock … decryption failed". Do not read that message as a lock conflict.
- To separate AND from OR (or any two readings), a capture needs a stack or row that the readings order differently. A single-tenant tree cannot do it.
- A sidecar test should recompute the input-root digest as well as the fixture digest, or editing the root goes unseen.
