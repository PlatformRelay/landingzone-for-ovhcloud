## Learnings

- sensor: path checks need a `..`-after-symlink row on both sides (the checked path and each root): `filepath.Abs`/`Clean` drop `x/..` before `x`'s link is followed; resolve with `EvalSymlinks` on the uncleaned absolute path.
- sensor: "refused when inside" also needs the admitted side to receive the checked path: a relative `TMPDIR` passed the check and reached children relative (`TF_DATA_DIR` under the root tofu runs in). Assert the child's HOME/data directory, not only the verdict.
- sensor: a mutant that makes a path not exist is caught by an unrelated "does not resolve" refusal; make the mutated path exist so only the clause under test can kill it.
- spec: a start that cannot record what its cleanup needs must refuse at start, not at cleanup (after the spend).
- tooling: `t078-mutants.py` (32), `t078-gates.sh`, `t078-red.sh`, `t078-focus.sh` (optional `-run` regex as `$1`).
