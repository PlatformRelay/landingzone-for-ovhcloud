## Learnings
- tooling: data sources read at plan time are absent from `resource_changes` in a `tofu test -json -verbose` plan (only their configuration references show); pin a read through what it returns (URN), not its arguments.
- sensor: a component-scoped call rule needs the same reachable-module walk as the state-backend rule (remote sources below a reached module escape the scan); apply it whenever a rule bounds instances of a retained module.
- guidance: a capture case (stage + run) generalises the stage-plan routine; sidecar checks must pin both the stage and the run.
- guidance: build `unlabelled` from the toggles, not from computed ids, or it is unknown at plan time.
