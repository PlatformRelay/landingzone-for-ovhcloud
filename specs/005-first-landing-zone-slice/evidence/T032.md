## Learnings
- tooling: a stage newly added to `singleComponentStages` can break fixtures in other packages that reuse the stage's path (`lz-check` `TestUnitSliceDiscovery` used `stages/runtime`); grep `tools/` for the stage path before adding the row.
- sensor: a plan pin can read `test_plan.configuration` (module call sources, argument references, constants) to prove which module a call reads; compare reference lists exactly, not with `contains`.
- guidance: a `tofu test` red on a missing output is `Reference to undeclared output value` even inside `try()`; prove the output test with mutants instead.
