## Interface added (beyond T035's pinned `Reconcile`)
- `stacks.PinnedTerramate(root)`: `LZ_TERRAMATE`, else `/tcb/terramate`, else `terramate` on `PATH`; the chosen binary must print exactly `root/mise.toml`'s `aqua:terramate-io/terramate` pin, or it is refused (never skipped for the next candidate). Same order and check as T035's `pinnedTerramate` test helper.
- `stacks.CheckStacks(root, terramate) ([]string, error)`: copies the root's `*.tm`/`*.tm.hcl` files and every regular file under `stacks/` to a scratch directory (a symlink or other non-regular file is refused), runs `Reconcile` with `Check` there, then `terramate generate` there, and returns `missing stack <path>` per missing stack (manifest row order) then `stale generated file <path>` per file that differs, is absent or is extra (sorted). Candidate never written. T037's authoring flow can call it directly.
- `stacks.ErrNoManifest`, `stacks.ManifestPath`.
- `lz-stacks [-root r] reconcile [-check]` prints `created <path>` (or under `-check` `fail: missing stack <path>`, exit 1); `lz-stacks [-root r] check` prints `pass` or one `fail: …` per finding, exit 1; refusals and pin errors one `fail: …` line, exit 1; usage exit 2. The manifest's presence is checked before the pin, so `fail: no manifest` needs no Terramate.
- Reconcile hardening against the T035 throw-away: discovery reads `*.tm` too, sorted (`os.ReadDir`, sorted attributes), refuses a second `stack` block in a directory, a non-string `id`, non-string-list `tags`/`after`, and two stacks with one id (UNSUPPORTED_CHANGE on the lexically later path); `after` filters deduplicated; a list with duplicates never equals the derived set; parse/walk errors returned instead of dropped.
- (r1) Before anything is written, every stack path to be created is checked component by component with `Lstat`: a file or symlink at the path or on its way is `UNSUPPORTED_CHANGE` naming that stack (so all-or-nothing also holds for obstructed destinations, and nothing is created through a link). A `terramate create` that fails afterwards (a tool error) can still leave earlier stacks; the doc comment says so and the CLI prints the `created` lines it got.
- (r1) `stacks:check` neither copies nor compares OpenTofu working files under `stacks/` (the `.gitignore` OpenTofu set: `.terraform`/`.terragrunt-cache` dirs or links, `*.tfstate`, `*.tfstate.*`, `*.tfplan`, `*.tfplan.json`, crash logs): never generated, possibly large, and state is secret-bearing.

## Learnings
- sensor · All-or-nothing needs a preflight on every destination, not only on the manifest/tree comparison: a file or link where a directory must be created breaks it after earlier writes (codex r1). Pin with an obstruction control and a "no write through the link" check.
- sensor · An exclusion list on a freshness diff must never be able to hide a generated file: exclude by exact working-file shapes and let source suffixes win (codex r2). Any filter shared by two commands (discovery, check) must be the same function, or they disagree on one tree (Opus r2).
- tooling · Test snapshots that `ReadFile` every entry break on a symlink to a directory; tests that plant links need an `Lstat`-aware snapshot.
- tooling · `lz-stacks` resolves Terramate exactly like the T035 tests (`LZ_TERRAMATE` > `/tcb/terramate` > `PATH`, exact pin); on this host set `LZ_TERRAMATE` to mise's 0.17.3 for `task stacks:reconcile`.
