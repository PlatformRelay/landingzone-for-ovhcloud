## Learnings
Class: sensor. (1) `tofu test` with `command = apply` exposes the root's outputs as `test_state.values.outputs`, byte-for-byte the `tofu output -json` shape: a mocked producer can feed a real publisher offline. (2) A name-substring check for "no sensitive output" is fooled by a plain output whose name extends it (`platform_s3` vs `platform_s3_user_id`): check names as keys and values as leaves. (3) A test task's tests that need tools only the tagged tier has go under that build tag, so untagged gates and CI stay green between the test task and its implementation. (4) A binding check needs one case per field (id only, URN only) and one where the forged values name another bound scope, or an implementation that takes the expectation from the artefact passes; write that mutant before the cases. (5) "Nothing written" must be observed at the writer (a recording store), not at a scratch store that happens to reject the call. (6) A pinned value in a generated test (`variables { project_id = … }`) hides whether the var file under test is read: strip it in the test copy.
