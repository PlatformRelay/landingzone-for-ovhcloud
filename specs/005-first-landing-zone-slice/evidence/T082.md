## Learnings

- sensor: a "no value leaks" check must also look at the test's working directory: a published value used as a relative path (`TF_VAR_state_path`) made the pre-guard fake write a file named after it into the package directory, unseen by root/run/stack scans (Opus r1).
- sensor: a red run of a leak control can itself leak into the tree; check `git status --untracked-files=all` after every red run, before committing.
- guidance: a deny-list of reserved names invites "what about X" findings each round; the coordinator may prefer an allow-list (proposal under *Harness gaps*).
- tooling: `t082-mutants.py` (33, mutates the worktree's `runner.go` in a scratch copy), `t082-gates.sh`, `t082-r1.sh`.
