## Learnings
- guidance: for a CIDR containment rule, test both edges of every block: a parent prefix of 10/8 or 192.168/16 grows upward, of 172.16/12 downward (`172.16.0.0/11` = 172.0.0.0/11 admits 172.15/16).
- tooling: a pin written as `func(t testing.TB, data []byte)` can be run on mutated plans through a recorder that embeds `testing.TB`, records `Error*`/`Fatal*` and `runtime.Goexit`s on fatal; recover panics and record skips so neither counts as a refusal.
- sensor: editing a stage's own test file stales its captured plan (the sidecar digest covers it), and the capture cannot be redone while the stage has red runs (`tofu test` exits 1): a test task on a pinned stage leaves the pin stale until its implementation task recaptures.
- guidance: when a check is added beside existing layers, look for rows the old layers do not already refuse; if all remaining rows break both new clauses, a per-clause mutant gate needs pairwise mutants.
