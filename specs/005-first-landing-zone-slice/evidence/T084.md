## Learnings

- class `sensor`: Go's `net/http` quotes answer-controlled text in its errors (an unparseable
  Location header, a malformed chunked trailer): `%w` on a transport or body error is an echo
  path; credential-echo rows need these two shapes, not only bodies.
- class `sensor`: a page bound needs both sides pinned (exactly N pages pass, page N+1 never
  asked); a lenient `≤ N+1` assertion let the off-by-one mutant live.
- class `guidance`: a test row whose expected label is `""` checks nothing (`Contains(x, "")`);
  give every "error names X" row a non-empty X.
