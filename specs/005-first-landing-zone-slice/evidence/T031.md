(5) "optional `slot`" = published when set, null (absent) when not, never a placeholder.

## Learnings
- tooling: tofu 1.13.0 refuses `run.<name>.<output>` inside an `assert` (`Reference to undeclared resource`); compare runs by pinning distinct literals.
- guidance: a test task's stub leaves the variable rules out, or its refusal runs pass on the stub.
- guidance: "unprotected module" is testable in `tofu test` as an apply run plus a `plan_options { replace = [...] }` run in its own file: a protected module's `prevent_destroy` refuses both.
