## Design notes (readings; believed unless marked)
- G7 static scan placed in `lz-check deps` (`ScanDependencies`), as T026's Verify already names "static lifecycle scan via `lz-check deps`": new rule `RETAINED_UNPROTECTED`, a list `retainedModules` (`modules/object-storage-protected`; **T026 adds `modules/cloud-project` to the same list and reuses the rule**). It applies to library directories of a retained package (subdirectories included, its `tests/` helpers excluded): every `resource` block needs a `lifecycle` block whose `prevent_destroy` evaluates, without context, to the literal bool `true`; a `removed` block is refused; a module source that is not a relative path is refused (its resources cannot be scanned, including this repository's own address with a ref; reviews r1, r2). Relative calls are the package's own subdirectories (scanned) or `modules/naming` (resource-free; any other module→module edge is already a `LAYER_VIOLATION`). Override files are judged block by block, not merged, so an `_override.tf` switching it off is caught, and one that only changes tags must repeat the lifecycle block (fail-closed; README says so; codex r1 minor accepted).
- A retained package with no resource passes (the purity fixture's `modules/object-storage-protected` holds only a module call); the module's own tests pin `ovh_cloud_project_storage.this`. A missing or renamed retained directory passes the rule silently (harness gap 2).
- Deny statement as in the kb example (`Resource = ["*"]`, `Sid` `DenyListAllBuckets`). The Allow statement is T013's throw-away plus the three multipart actions of the kb read-write example (within T013's allowlist).
- kb `s3-identity-and-access-management.mdx:100-106` (verified 2026-10-07): an action with neither explicit Allow nor Deny falls back to ACLs; what `objectstore_operator` grants through them is UNVERIFIED (README says so; T013 gap 4, T010).

## Learnings
- tooling: a static rule that trusts a resolved module path must first refuse sources that only look local: this repository's address with `?ref=` resolves to a local directory but tofu fetches another revision (r2). For "is this code scanned", accept only `./`/`../` sources.
- tooling: a G7-style lifecycle scan lives in `lz-check deps` (`retainedModules` + `RETAINED_UNPROTECTED`); T026 adds `modules/cloud-project` to the list and reuses the rule and its rows.
- guidance: a per-file mutant ("first file only") needs a control whose bad file sorts after the good one (`zz_extra.tf`), or the mutant survives by walk order.
- guidance: a README claim of what a credential cannot do must hold under every evaluation path the provider documents (here the ACL fallback), or be marked UNVERIFIED.
