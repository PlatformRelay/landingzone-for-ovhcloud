- **Fake tofu** (`runner_test.go`) echoes every `ScanFor` value it holds in its environment to stderr, under its key name, so the terminal checks cover mixed-case keys (T079 Opus r2 gap).

## Readings

- Prefix case is significant: `TF_VAR_P25_client_id` and `TF_VAR_p25_client_secret` are two half pairs → refused (T079 left it open; a `TF_VAR_` name is case-sensitive to OpenTofu).
- Two ids (or two secrets) of one prefix in different suffix case → refused.
- A lone `…_clientid` (no separator, no secret) is not credential-shaped under the narrow reading and passes (an id alone is no secret); `…_clientsecret` is refused (`secret` suffix). The T079 `no separator` row publishes both and is refused.
- The default identity counts only under exactly `OVH_CLIENT_ID` and `OVH_CLIENT_SECRET` (the provider reads only those names): `OVH_CLIENT_ID` + `OVH_Client_Secret` pairs by prefix but is refused (review r1, both legs).
- The suffixes match without a separator: `TF_VAR_ssh_public_key` or `TF_VAR_monkey` are refused too — an accepted consequence of the pin (Opus r1 note); a legitimate output so named must be renamed.
- Other credential-ish names not in the suffix list (`…_PASSWD`, `…_CREDENTIALS`, `…_KEYS`) pass (whereas e.g. `AWS_SESSION_TOKEN` is refused by `token`, and `aws_secret_access_key` in another case by `key`; `aws_access_key_id` in another case passes, being no credential-shaped name — codex r1 minor): the narrow reading's accepted consequence; every published value is still redacted from all output by value (`runner.go` `s.red.Add`).
- The refusal error names keys only, never values (verified by reading; `checkRefused` scans the returned error).

## Learnings

- sensor: a case-insensitive rewrite of a lookup must keep the exact-name requirement where a consumer reads exact names (the provider reads only `OVH_CLIENT_SECRET`); pin it with an "other case" refusal row (review r1, both legs).
- sensor: a terminal-leak check is only as strong as what the fake prints; a fake that echoes every scanned value under its own name makes a by-name redaction mutant observable (echo proof: killed with, survives without).
- tooling: brief edits for round 2 need a Read of the copied file first, else the Edit fails silently in a batch and the round runs on the old brief; write round-2 briefs fresh with Write after a Read.
- tooling: `t080-mutants.py` (29, real `runner.go` in a scratch copy), `t080-echo-proof.sh`, `t080-gates.sh`.
