## Readings (believed unless marked verified)
1. A client missing under `--fresh-account` (sandbox.env names a client that no longer exists, or its credential is rejected) is not "an admin that exists": the run lists the account's clients with the root keys and creates the admin only when none is named `lz-sandbox-admin`; otherwise it refuses (decision 3). A policy left bound to a deleted client's identity is not looked for (gap 3).
2. The endpoint is fixed to `ovh-eu` in the entry: the admin URNs are the `eu` form and the sandbox is on ovh-eu (AGENTS.md); a second endpoint needs a flag and the URN form (UNVERIFIED for ca).

4. Root-key timestamps use the API clock: `GET /auth/time` (no authentication, kb `auth.json`) once, before the first signed call. The fake answers with local time, so the offset itself is UNVERIFIED until T045.
5. The production terminal is `/dev/tty` opened read-only (lz-live writes no file outside files.go), echo cleared with `TCGETS`/`TCSETS` around each secret read and restored on every return, prompts on stderr; a cancelled run context abandons a pending read. Linux only; elsewhere `--fresh-account` stops before any key is read.

## Learnings
- guidance: a deferred cleanup that joins into a named result is lost when an inner block shadows `err` (`x, err := …`); name inner errors differently in functions with such a defer.
- guidance: when a cleanup can fail after a refusal, decide the exit-code precedence explicitly; `errors.Join` lets the refusal win `errors.As` (review r1).
- guidance: a check that classifies API answers needs a third outcome for "the API failed", or a 5xx reads as drift and the advice destroys a healthy resource (review r2).
- sensor: v2 listings paginate (`X-Pagination-Cursor-Next`); a fake that never paginates hides a first-page-only reader — give fakes a page-size knob.
- tooling: a pseudo-terminal test needs `/dev/ptmx` opened non-blocking (`syscall.Open` + `os.NewFile`) or read deadlines never fire and the test hangs.
