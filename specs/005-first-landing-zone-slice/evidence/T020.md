## Scope of the rule (decision taken here, counterpoint recorded)
The rule covers **libraries (modules, components), stages and generated instances (stacks)**; test configuration (test files, helper modules under `tests/`, root `tests/`) and examples are out of scope.
- Why wider than the dispatch's library default: the envelope builder (G2, `tools/internal/stacks/outputs.go:240-263`, read 2026-10-07) drops exactly the entries `tofu output -json` marks sensitive, and trusts that mark. The outputs it reads are the stack's, which re-export the stage's. A `nonsensitive()` in a stage or stack is therefore the shortest way around G2, and a stage's slice tests cannot enumerate its outputs any more than a module's unit tests can (the T019 gap's reason holds at every deployed layer). No deployed configuration in the repository calls it today (grep, 2026-10-07: only `tests/*.tftest.hcl` do), so the wider scope costs nothing now.
- Why tests and examples stay out: test files assert on secrets with `nonsensitive()` (four existing files); test helpers and examples are never deployed.
- Counterpoint: a later stage or module may need `nonsensitive()` for a legitimate non-secret use (e.g. a `for_each` key derived from a sensitive-marked input). The rule then forces an explicit decision (a narrower rule or an exemption list), which is the intent; it is not an allow-list to widen silently.
- Match: any function call whose name is `nonsensitive` or ends in `::nonsensitive` (`core::nonsensitive`, a provider function of that name), found by walking every expression of the parsed file (`hclsyntax.VisitAll`: attributes, nested and dynamic blocks, templates, heredocs, for expressions, check blocks). Comments, strings and other names containing the word are not calls.

## Learnings
- tooling: `hclsyntax.VisitAll` always descends (the callback's return does not prune), so a "skip a subtree" mutant must change the root node instead (`VisitAll(body.Attributes, …)`).
- tooling: a mutant that slices (`bodies[:1]`) can panic on an empty case and fail an unrelated test first; bound it (`[:min(1, len(x))]`) or the target-test judgement reports a false SURVIVED.
- guidance: a static rule guarding a publish boundary belongs on every layer that reaches the boundary (here library, stage, instance), not only where the gap was first seen; state the scope and its counterpoint in the evidence.
