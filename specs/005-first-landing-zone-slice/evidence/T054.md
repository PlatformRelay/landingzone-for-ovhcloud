## Interface the tests pin (for T055)

- `live.Runner{ID, Dir, Tofu, Authority, Creds, Vars, Stacks []Stack{ID, Dir, Ephemeral}, Deadline, Protect func(Stack, []byte) error, Leftovers LeftoverCheck, Terminal, Signals <-chan os.Signal, StateListFallback}` with `Execute(ctx) error` (named `Runner`: `live.Run` is T053's guard entry). Per stack in order: `tofu -chdir=<dir> plan … -out=<file>` → `show -json <file>` → `Protect(stack, json)` → `apply -json … <file>` (exactly that file); `show <file>` rendered to `<Dir>/plan-<id>.txt`. Destroy-on-exit (also after success): every ephemeral stack whose apply started, reverse order, `destroy` (or `apply -destroy`, or a destroy plan), continuing after a failure, with its own time after the deadline. A stack whose plan failed or that was never reached is not destroyed; a retained stack never is. Then the leftover check, `<Dir>/listings/<type>.json`, `<Dir>/summary.json` (`outcome` pass|fail) and the terminal lines `LZ-LIVE summary <id> <outcome> …` and `record approximate cost for run <id> in the PR`. A `*Refusal` from `Protect` keeps exit 3; any other failure is non-zero. `Signals == nil` means SIGINT/SIGTERM of the process (tested in a fresh process). `DefaultDeadline = 45 min`.
- Child environment: one scratch HOME per run, 0700, removed when `Execute` returns, shared by every `tofu` and `ovhcloud` child; environment = PATH, HOME, `TF_*`, the run's `Creds` (an allowlist, as T053's `Command`). Every value of `Creds` is a secret: redacted from the terminal (child stdout and stderr included) and every file of the run record.
- `live.NewRedactor(secrets...)`, `Redact(string)`, `Writer(io.Writer) io.WriteCloser` (holds back a possible secret prefix across writes; `Close` flushes; empty secrets ignored; other text byte-exact).
- `live.OpenInventory(runDir, *Redactor)`, `Append(InventoryEntry{Stack, Address, Type, ID})`, `AppendStateList(stack, io.Reader)` (P24 fallback: new managed addresses, data sources skipped, type from the address), `ReadInventory(runDir)`, `ConsumeApply(r, stack, inv, out)` (appends each `apply_complete` before reading the next event; reopen appends).
- `live.LeftoverCheck{Ovhcloud, Lister, Projects []Project{ID, URN}, Prefix, RunID, Retained map[type][]id, Exempt Exemption{ClientID, PolicyID}}.Check(ctx, inventory) Report{Outcome, Leftovers []Leftover{Type, ID, Name}, Errors, Listings}`; `Lister.Get(ctx, path, cursor) (body, next, error)`; `MatrixTypes()` = R12's 13 types; `LoadExemption(configRoot, account)` (client id from `sandbox.env` `OVH_CLIENT_ID`, policy id from `accounts/<a>/account.env` `LZ_ADMIN_POLICY_ID`, both via `ReadCredentialFile`, both required). Listing paths are the kb/api v1/v2 GET paths (see the fixture): per project `/region` then `/region/{r}/storage`, `/network/private` then `…/{n}/subnet`, `/user` then `…/{u}/s3Credentials` and `…/{u}/policy`, `/alerting` then `…/{id}`, `/iam/resource/{urn}` (tags); account `/me/api/oauth2/client` then `…/{id}`, `/iam/policy` (paged), `/me/identity/group` then `…/{name}`. Ids: bucket name, network/subnet id, user id, S3 access key, S3 policy = its user's id, client id, policy id, group name, tag key, alert id.
- Matching rule pinned by the seeds: a listed resource is a candidate when its name starts with `Prefix`, its id, name or tag value holds `RunID`, its (type, id) is in the inventory, or its parent is a candidate; it is a leftover unless retained (its id in `Retained[type]`, or its parent retained for children) or exempt (client/policy by exact id only).
- `live.Probe{Run, ConfigRoot, Account}` with `Start(ctx)` and `Cleanup(ctx)`; `ProbeDir(root, account, runID)` = `<root>/accounts/<a>/state/probes/<run-id>` (run id `YYYYMMDDThhmmssZ-<4 hex>`, else an error). Files: `<stack id>.tfstate` and `passphrase.env` (`TF_VAR_state_passphrase`, ≥ 16 characters, new per run, 0600, directory 0700); children get `TF_VAR_state_path` and `TF_VAR_state_passphrase` (environment, never argv). Both files deleted only when destroy and the leftover check pass; `Cleanup` destroys from the retained files without applying and fails (destroying nothing) without the passphrase.
- Not pinned (left to T055): `init` flags, the `ovhcloud` argv per listing (UNVERIFIED for 0.15.0; T065 qualifies), the redaction placeholder, `leftovers.json`, `observations.json`, summary fields other than `outcome`, the `cmd/lz-live probe [--cleanup <run-id>] [--deadline]` flag parsing (T055 adds its `TestUsage` rows), whether a stack's `init` runs per run.
