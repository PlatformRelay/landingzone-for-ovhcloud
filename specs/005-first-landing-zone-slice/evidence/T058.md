8. **Selection** (R21): `all` acts on `stacks.Select`'s set (minus account-bootstrap) in run order; `-- <instance>` acts on that instance and is refused (`producer-selected`) when a producer it consumes is selected. The steady state ("a complete earlier run") is seeded independently of the lane: fake states, artefacts through `Publish`, deployer files through files.go, records with `CodeDigest`, consumed artefact digests and `stacks.Adapt`'s resolved digest.

10. **Inputs**: every `-var-file` of a plan lies in `<run-dir>/inputs/<id>/` (`stacks.Adapt`'s directory, data-model step 3); the fake requires the roots' inputs without default (`state_project_id`, `tenants`, `project_id`, `project`) with the bound values, so a lane that skips the adapter cannot plan (T056 lesson). 13. **`show -json` carries the root's variable values**, the sensitive passphrase among them (believed for OpenTofu 1.13; the fake adds it), so keeping the raw document is keeping a secret (review r1).

## Learnings
- sensor: a harness's lock-lifetime check must end at the last side effect of the run (publication, record), not at the last child call (review r2).
- sensor: a guard pinned only by rows of the guarded kind lets an implementation skip it elsewhere; add a row of the other kind that the guard must still refuse (errored ephemeral plan; review r2).
- sensor: a lane harness sets a fake `HOME`/`XDG_CONFIG_HOME` and never prints an unseeded value of a secret variable in a failure message (review r2; `bootstrap_admin_test.go` already did).
- sensor: a "file removed" check names the paths the run logged, not a suffix; a "record kept" check reads content, not existence (review r1/r2).
- guidance: every refusal row runs under each verb and target form that reaches the guard (`apply -- all`, `apply -- <id>`, `plan -- all`; review r1).
