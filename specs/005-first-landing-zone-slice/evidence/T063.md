## Interface the tests pin (for T064)

- `live.Protect(plan []byte, retained []Retained) error` — `plan` is `tofu show -json` of a saved plan; pure (no I/O). Fits T054's `Runner.Protect func(Stack, []byte) error` through a closure that supplies the stack's retained set.
- `live.Retained{Instance string; Addresses []string}` — one retained instance and its resource addresses in the planned root (T057: "the account bucket and platform S3 user as the retained set"; T059: state-list addresses). An address covers itself, its instances (`a.b` covers `a.b["k"]`) and, for a module address, every resource under it and under each of its instances (`module.m` covers `module.m.x.y` and `module.m["k"].x.y`); never a sibling sharing a prefix (`terraform_data.project` does not cover `terraform_data.project_scratch`; `module.gov` not `module.governance`; `module.region["c"]` not `module.region["ca"]`). An entry with no addresses covers nothing (stated in the stub, not pinned; see gaps).
- Refusal: `*Refusal{Condition: CondRetained}` (`CondRetained = "retained"`, the literal T054's runner test already uses), so `ExitCode` is 3; the error names every refused address verbatim (unquoted: `strings.Contains` on `tenant_bucket["beta"]`) and the instance it belongs to; it never carries a value from the plan.
- Refused: any `resource_changes` entry of a covered address whose actions contain `delete` or `forget` (`["delete"]`, `["delete","create"]`, `["create","delete"]`, `["forget"]`), judged by the actions whatever the `action_reason` (incl. `replace_by_request` from `plan -replace`), whether or not the configuration still declares it; a plan that is not valid JSON, is truncated, lacks `format_version` (`null`, `[]`, `{}`), has the wrong shape (`"resource_changes":"none"`) or is marked `errored`.
- Admitted: `no-op`, `create`, `update` of a covered address; any change of an address no entry covers.

## Learnings

Class: sensor.
- A guard keyed on addresses needs prefix-sibling and keyed-instance rows at every level it matches (resource, module, module key); one level's sibling row does not pin the others (both review rounds).
- Judge plan changes by `actions`, never `action_reason`: `plan -replace` gives `replace_by_request`; pin it with a captured fixture (r1).
- A digest sidecar must be bound to its file name, not to a field inside it (r1).
- OpenTofu 1.13 keeps a forgotten resource in `planned_values`; a mutant's targets must be checked against the captured shape before calling a survivor a gap.
- Capture scripts in the repo must not `rm -rf` a caller path; refuse an existing one.
