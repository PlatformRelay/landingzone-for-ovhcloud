## Interface and readings the tests pin (this task's choice, believed; the plan fixes only file names)
- **Go** (`generate.go`): `Generate(GenerateOptions{Root, Terramate}) error` decodes `Root/stacks/deployments.yaml` (decoder refusals as `*ManifestError`), refuses `spec.stage_source.kind: git` with `*GenerateError{Code: STAGE_SOURCE_NOT_IMPLEMENTED}` before writing anything, and runs the pinned `terramate generate` in `Root`. `PlannedBucketNames(plan []byte) ([]string, error)` reads a plan JSON (`tofu show -json` form, the `test_plan` of a verbose `tofu test -json` message): the `name` of every managed `ovh_cloud_project_storage` not being deleted, sorted; a name unknown at plan time is an error, never skipped. `CheckPlannedNames([]StackPlan{Stack, Plan}) error` refuses one name planned twice with `*GenerateError{Code: NAME_COLLISION, Path: <the later stack>}`, the detail naming the bucket.
- **Generation configuration**: the repository's root `*.tm`/`*.tm.hcl`, `stacks/*.tm.hcl` and `stacks/_lz/**` (T038), copied into a scratch Terramate root with the fixture manifest; no other repository file is visible to generation.
