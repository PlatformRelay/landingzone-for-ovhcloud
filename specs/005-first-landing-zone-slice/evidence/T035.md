## Interface the tests pin (this task's choice, believed; the plan fixes only the file names)
- `Reconcile(ReconcileOptions{Root, Terramate, Check}) (ReconcileReport, error)`. `Root` is a Terramate project root holding `stacks/deployments.yaml`; `Terramate` the pinned binary; `Check` reports without writing (`--check`).
- `ReconcileReport.Created`: stack paths (`stacks/…`, slash-separated) created, or under `Check` those that would be, in manifest row order.
- Refusals: a decoder refusal is returned as the decoder's `*ManifestError` (so `STAGE_NOT_IMPLEMENTED` is the decoder's code, decision 1); every tree mismatch is `*ReconcileError{Code: UNSUPPORTED_CHANGE, Path, Detail}`.
- **All or nothing**: every mismatch is found before the first `terramate create`, so a refused run writes nothing.
- A stack is a directory under `stacks/` whose Terramate config holds a `stack` block; a config-only directory (`stacks/_lz/`) is not one.
- Metadata of a created stack (`stack.tm.hcl`, parsed with `hclsyntax`): `id` = instance id; `tags` = the decoded instance's tags; `after` = one tag filter per edge whose producer is a row: `tag:lz-stage-<stage>` plus the producer's `lz-tenant-`, `lz-env-`, `lz-region-` and `lz-slot-` tags where set. An `external` producer (tenant-only manifest) gives no `after`: it is not a stack of this repository. `name`/`description` are not pinned.
- Reconcile creates metadata only (`terramate create --no-generate`): generation is `stacks:generate`'s step (contracts/checks.md).
- "Any other mismatch" (FR-007) read to include an existing stack whose `tags` or `after` differ from the derived ones (otherwise a hand-edited `stack.tm.hcl` passes `stacks:check`, which only diffs generated files after reconcile `--check`).
- Pinned Terramate: the test takes `LZ_TERRAMATE`, else `/tcb/terramate` (inside `lz-offline`), else `terramate` on `PATH`, and fails unless `terramate version` equals the `aqua:terramate-io/terramate` pin in `mise.toml` (0.17.3). The host's `~/.local/bin/terramate` is 0.17.1 (verified 2026-10-07), so on the host the Verify line runs with `LZ_TERRAMATE` pointing at mise's 0.17.3 install.
