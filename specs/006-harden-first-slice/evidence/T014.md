## Learnings

Class: guidance.
- A reader that agrees with a writer must apply the writer's path checks from the same base: checking symlinks from a deeper directory than the writer leaves the ancestors open (round 2).
- A retry that takes an interrupted write as done owes the write's remaining cleanup; test it through the crash step that skips that cleanup.
- Name the base directory and every ancestor in a symlink test (root-relative), not only the leaf directories the code creates.
