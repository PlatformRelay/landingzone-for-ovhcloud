## Readings (for T033)

Data-model fixes the signatures but not every input's meaning. The tests read them as follows (believed: the readings; each follows `prepare.py`, which T033 ports):

- `PrepareOptions.Archives` maps each fetched artefact's **pin-table name** to its local file: the release archives by tool (`go`, `tofu`, `terramate`, `task`, `tflint`, the keys of `checks.Artifacts`), the packages and the provider by file name (keys of `checks.Packages`). The network fetch stays host-side (research R6 *Note*).
- `Toolchain` is the qualified toolchain root `prepare.py` calls `LZ_TOOLCHAIN_ROOT`: `tools/go/go/…`, `tools/tofu/tofu`, `tools/terramate/terramate`. `Root` is the private preparation root: `proof/go-files.sha256` (`<sha256>  <absolute path>` per Go file) in, `bundle/` out, `bundle/` and `staging/` absent before.
- `Crane` is run as `crane export --platform=linux/amd64 <checks.Image> -` (`prepare.py`; `--platform linux/amd64` also accepted); the tests use the test binary itself as crane (`TestMain` answers `export` with the fixture image, and only for the pinned image on that platform), so no shell or network is needed inside the sandbox.
- **Refusal, not a safe projection.** An archive with an escaping member, link or write-through is refused outright, as `prepare.py` refuses it (`unpack`: "unrooted image member", "escaping image link", "member through or over a link"); a projection that silently resolves such names inside the root (RESOLVE_IN_ROOT style) fails these rows by design.
- **Pins.** Admit compares the recorded pins with the checks tables, and the fixtures cannot have the real archives' digests, so `useFixturePins` points `checks.Artifacts` and `checks.Packages` at the fixtures' digests for each test and restores them. The provider zip's pin is put in `checks.Packages`: data-model extends that table to every artefact kind (`archive|apk|provider|image`). `useFixturePins`, `setFixturePin` and `dropFixturePin` are the only code that knows the tables' shape (every row's pin change goes through them); when T033 changes `checks.Packages` to data-model's per-artefact rows, those helpers change with it (a TEST-class change citing data-model *Runtime preparation inputs*; no claim changes). Consequence for T033 (believed): once the provider pin (and any other non-apk artefact) joins `checks.Packages`, `AdmitPins`' exact comparison (`tools/internal/checks/toolchain.go:60`) refuses every bundle `prepare.py` wrote, so T033 updates the table's comment (`toolchain.go:21`, "Wolfi packages unpacked into the image's root") and the bundle is re-prepared with the Go command.
- **Launcher seam.** `Prepare` records the launcher's digest (`resources.json` `bwrap_sha256`, read by `Admit`). The entry's sandbox has no `/usr/bin/bwrap` (its root is the image rootfs, `tools/cmd/lz-offline/main.go:532`; verified 2026-10-16), and `PrepareOptions` has no launcher field, so `prepare.go` declares `var launcherFile = Launcher`, which the internal test points at a fake. `resources.json` still names the fixed path `Launcher`. Precedent: the nil-in-production seams of T018, T019, T023. (The test is in package `bundle` for this reason; its helpers carry `fixture`/`test` names so they do not take names T033's code may want, `project` among them.)

## Fixtures

`tools/internal/bundle/testdata/prepare/` (15 files, ~70 KB) is written by a deterministic generator kept outside the repository (`~/.local/share/ovh-lz/review/t030-gen-fixtures.py`; fixed mtime, owner and gzip header). Run twice into different directories on this host, the outputs are byte-identical (verified 2026-10-16, `sha256sum` diff empty; Python 3.14.6, zlib 1.3.1.zlib-ng). Gzip output depends on the zlib build: a review leg's regeneration elsewhere matched 14 of 15 files, the libpcre apk compressing to 197 bytes instead of 194 with identical content. The tests read the committed bytes, so this only matters for regeneration. The generator, inlined:

```python
# python3 -I t030-gen-fixtures.py tools/internal/bundle/testdata/prepare
"""Write T030's fixture archives into <out> deterministically.

Usage: python3 -I t030-gen-fixtures.py <out-dir>
"""
import gzip
import io
import sys
import tarfile
import zipfile
from pathlib import Path

OUT = Path(sys.argv[1])


def member(name, kind, data=b'', link='', mode=None):
    info = tarfile.TarInfo(name)
    info.mtime = 0
    info.uid = info.gid = 0
    info.uname = info.gname = ''
    if kind == 'dir':
        info.type, info.mode = tarfile.DIRTYPE, mode or 0o755
    elif kind == 'file':
        info.type, info.mode, info.size = tarfile.REGTYPE, mode or 0o644, len(data)
    elif kind == 'sym':
        info.type, info.mode, info.linkname = tarfile.SYMTYPE, 0o777, link
    elif kind == 'hard':
        info.type, info.mode, info.linkname = tarfile.LNKTYPE, 0o644, link
    return info, data


def tar_bytes(members):
    buffer = io.BytesIO()
    with tarfile.open(fileobj=buffer, mode='w', format=tarfile.USTAR_FORMAT) as archive:
        for info, data in members:
            archive.addfile(info, io.BytesIO(data) if info.isreg() else None)
    return buffer.getvalue()


def gz(data):
    buffer = io.BytesIO()
    with gzip.GzipFile(fileobj=buffer, mode='wb', mtime=0, filename='') as stream:
        stream.write(data)
    return buffer.getvalue()


def zip_bytes(name, data):
    buffer = io.BytesIO()
    with zipfile.ZipFile(buffer, 'w', zipfile.ZIP_DEFLATED) as archive:
        info = zipfile.ZipInfo(name, date_time=(1980, 1, 1, 0, 0, 0))
        info.external_attr = 0o755 << 16
        archive.writestr(info, data)
    return buffer.getvalue()


def write(name, data):
    (OUT / name).write_bytes(data)


VALID = [
    member('bin/', 'dir'),
    member('bin/tool', 'file', b'tool\n', mode=0o755),
    member('etc/', 'dir'),
    member('etc/conf', 'file', b'conf\n'),
    member('usr/', 'dir'),
    member('usr/bin/', 'dir'),
    member('usr/bin/sh', 'sym', link='/bin/tool'),
    member('usr/bin/rel', 'sym', link='../../bin/tool'),
]

OUT.mkdir(parents=True, exist_ok=True)
write('valid.tar', tar_bytes(VALID))
write('symlink-escape.tar', tar_bytes(VALID + [member('usr/bin/evil', 'sym', link='../../../outside/secret')]))
write('symlink-escape-absolute.tar', tar_bytes(VALID + [member('usr/bin/evil', 'sym', link='/../outside/secret')]))
write('symlink-through.tar', tar_bytes(VALID + [member('out', 'sym', link='../outside'), member('out/planted', 'file', b'planted\n')]))
write('hardlink-escape.tar', tar_bytes(VALID + [member('bin/evil', 'hard', link='../outside/secret')]))
write('hardlink-absolute.tar', tar_bytes(VALID + [member('bin/evil', 'hard', link='/etc/passwd')]))

write('image.tar', tar_bytes([
    member('bin/', 'dir'),
    member('bin/busybox', 'file', b'busybox\n', mode=0o755),
    member('etc/', 'dir'),
    member('etc/os-release', 'file', b'ID=fixture\n'),
    member('usr/', 'dir'),
    member('usr/bin/', 'dir'),
    member('usr/bin/sh', 'sym', link='/bin/busybox'),
    member('usr/lib/', 'dir'),
]))
for tool in ('go', 'tofu', 'terramate'):
    write(tool + '.tar.gz', gz(tar_bytes([member(tool, 'file', (tool + ' release\n').encode(), mode=0o755)])))
write('task.tar.gz', gz(tar_bytes([member('task', 'file', b'task\n', mode=0o755)])))
write('tflint.zip', zip_bytes('tflint', b'tflint\n'))
write('git-2.56.0-r0.apk', gz(tar_bytes([
    member('.PKGINFO', 'file', b'pkgname = git\n'),
    member('usr/', 'dir'),
    member('usr/bin/', 'dir'),
    member('usr/bin/git', 'file', b'git\n', mode=0o755),
])))
write('libpcre2-8-0-10.49-r1.apk', gz(tar_bytes([
    member('.PKGINFO', 'file', b'pkgname = libpcre2-8-0\n'),
    member('usr/', 'dir'),
    member('usr/lib/', 'dir'),
    member('usr/lib/libpcre2-8.so.0', 'file', b'pcre\n'),
])))
write('terraform-provider-ovh_2.21.0_linux_amd64.zip', zip_bytes('terraform-provider-ovh_v2.21.0', b'provider\n'))
```

A real apk is several gzip members whose control tar has no end blocks; the fixture apks are one member, which a stream reader reads the same way (believed). The archives' formats are standard (`archive/tar`, `archive/zip`), so no external tool's output is encoded by hand.

## Learnings

Class: guidance.
- A refusal test passes against a stub that refuses everything: pair every refusal row with an acceptance control in the same row, and prove the refusal half with mutants of a reference implementation kept outside the repository.
- A fixture with a fixed absolute path cannot show an escape the kernel itself blocks (`link(2)` to `/etc/passwd`): build that row at test time from a path the test owns.
- An internal test (`package x`) shares its package's namespace with the code a later task writes: give test helpers names production will not want (`projectFixture`, not `project`).
- Before re-running a review leg, check the brief edit applied (a failed edit sent a round-1 brief, again, until the run was stopped).
