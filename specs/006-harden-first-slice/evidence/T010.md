## Learnings

Class: guidance.
- An allow-list test needs, for each reserved name, a row with the exact admitted prefix and the rest in another case: lower and alternating case change the prefix too, so a case-sensitive reserved check survives them (the `reserved-case-sensitive` control).
- Inverting a "passes" pin into refusal rows: run the refusal rows through the same closures as the existing refused rows (exit, no child, no bind, no value left) and add the error-names-it check, so a run that refuses for the wrong reason still fails.
