## Learnings

Class: guidance.
- A requirement that names "the run's redactor" covers every run that runs the check, not only the one the task names: grep every production caller of the guarded type (`LeftoverCheck{`, `.Leftovers.Check`) before calling the change complete.
- When a component owns the redactor its records go through, it sets that redactor on what it calls; letting a caller-supplied one win splits the token from the records.
