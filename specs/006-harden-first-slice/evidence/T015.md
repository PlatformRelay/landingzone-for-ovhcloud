## Learnings

Class: guidance.
- A requirement phrased "no child process … on any path" covers every `exec.Command` of the binary, not only the helper the task names: grep `exec.Command` and `"HOME="` literals across the binary's packages before framing.
- git reads `$HOME/.config/git/ignore` even with `GIT_CONFIG_GLOBAL=/dev/null`; a guard's git needs a private `HOME` too.
- A helper that creates a resource and then can fail must clean it up itself: callers only remove what they were handed.
