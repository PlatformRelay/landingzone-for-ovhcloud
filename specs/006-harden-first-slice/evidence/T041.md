## What the gates do (verified 2026-10-19, read in `docs.go`)

- **Version gate** (`versionGate`, called once per page in the existing page loop). Pages under `docs/` except `docs/adr/` and `docs/known-issues/`. `verified_against` (a space before its colon allowed, review round 1) is read from the front matter as an inline mapping of quoted `major.minor` (optional patch) versions. Pins: `mise.toml` `[tools]` (`opentofu` → `tofu`, `aqua:terramate-io/terramate` → `terramate`, `task`, `tflint`, `go`), `mise.live.toml` `[tools]` (`github:ovh/ovhcloud-cli` → `ovhcloud`), and the `registry.opentofu.org/ovh/ovh` block of every `.terraform.lock.hcl` under `stages/`, `modules/`, `components/` (hidden and `fixtures` directories skipped, as the update-lane check does) → `ovh`. Minor distance by integer; more than two behind is `VERIFIED_AGAINST_STALE`; a key with no pin is `VERIFIED_AGAINST_UNKNOWN_TOOL`; a how-to or reference page that names a command without the mapping is `VERIFIED_AGAINST_MISSING`.
- **Superseded scan** (`supersededScan`, called once after the README loop). An ADR is Superseded when the first `- Status:` line of `docs/adr/NNNN-*.md` starts `Superseded` (the template, `docs/adr/README.md:75`). The scan walks the root, skips `docs/adr/`, `tools/vendor/`, `.git` and what the root `.gitignore` names, skips binary files and the generated CI run record `pipelines/github/foundation-runs.json` (review round 2, *Registry*), and reports `SUPERSEDED_ADR <file>: line N cites ADR-NNNN` once per file and ADR for `ADR-NNNN` or `adr/NNNN-`.
- `docs()` is unchanged in shape: three statements added (`c.loadPins()`, `c.versionGate(page, text)`, `c.supersededScan()`), complexity 23 before and after (gocognit, *Sensors run*). A read error of a pin file, lock tree, `docs/adr/`, `.gitignore` or the walk is an `INPUT_UNREADABLE` finding (fail closed) rather than an exit 2, which would have needed a new branch in `docs()`.
- `header()` now finds the closing `---` through `closingLine`, shared with the version gate; behaviour unchanged (existing `TestDocs*` rows green).

## Readings (what T039 left unpinned; independent-review)

Each is decided here; 1-3, 5-8 and 11 are pinned by `TestDocsGateReadingsRejected` / `TestDocsGateReadingsAccepted` (new, this task), 4, 9 and 10 by no test (they say what is not judged):

1. **Ahead of the pin** → `VERIFIED_AGAINST_STALE` ("ahead of its pin"), compared on major, minor and patch (a stamp ahead only in its patch is ahead too, review round 2). FR-018 names only "behind"; a stamp ahead names a version the repository does not run, so its claim cannot be about this repository, and a typo (`1.51`) would otherwise pass until the pin caught up. Kept under the existing rule id rather than a new one (data-model lists the ids).
2. **Major-version mismatch** → stamp on an older major is stale ("a major version behind"); on a newer major it is ahead (1).
3. **Malformed or block-form stamp** → `HEADER_MALFORMED` (the existing front-matter rule), including unquoted versions (YAML reads `1.10` as `1.1`), a major alone, `{}`, a tool given twice and the key given twice. Fail closed; a malformed stamp counts as present, so no second `MISSING` finding.
4. **Stamp omitting a tool the page names** → not judged. FR-018 requires the mapping on command pages, not a complete one; making it complete needs a per-tool command map that FR-018 does not ask for.
5. **Lock files disagreeing on `ovh`** → the newest version is the pin, so no page is judged against an older lock (rows with the older lock in the stage, then in the module, so neither a first-read nor a last-read reader passes). `stacks:check` already holds stack locks to stage locks (FR-011).
6. **ADR without a status line** → not Superseded; only a status line can say Superseded, a body word does not (ADR-0004:83 says "superseded input").
7. **"Tracked file" without git**: the entry's snapshot carries no `.git` (`tools/cmd/lz-offline/main.go:197`, T039's reading), so "tracked" is approximated by skipping `.git` and the root `.gitignore`'s plain and wildcard names (`agent-context/`, `.local/`, `.terraform/`, `*.tfstate`, …) at any depth (`/`-anchored ones at the root only). A negation or a pattern with an inner slash is not read; `name/*` skips all of `name/`, so `.claude/*` skips `.claude/` although `!.claude/skills/` re-includes that path (no file under `.claude/` is tracked today: `git ls-files .claude` empty, 2026-10-19). Tracked hidden directories (`.github/`, `.specify/`) are scanned.
8. **"Names a command"** (refining T039's word match, which T039 asked T041 to check against real hits): in code (block or span) any `tofu|terramate|task|ovhcloud` followed by spaces or tabs (review round 2) and a flag (`task --list`, review round 1; `task -C dir`, uppercase short flags, review round 2) or a word; in prose, `task` only with a flag or a namespaced or existing Taskfile target (the rule `TASK_TARGET` already applies, "this task has" is English), the other three with any following word ("run tofu plan", T039's prose row).
