## Learnings

Class: guidance.
- To show a context's budget without waiting for it, read `ctx.Deadline()` at a seam the code already calls under that context (here the Lister); it proves the budget only for the calls that share that context.
- A floor test (`max(default, run)`) needs a row above the floor at each call site as well as at the helper, or call sites wired to the constant pass.
- "Counted from when" is part of a budget: make the phase before it take measurably longer than the slack, or a budget counted from the run's start passes.
- An existing test that uses a fixed wait to stand for "longer than the destroy's time" breaks when that time grows: run the whole package under an `impl` control before review.
- Amending the commit a docs pin's `last_verified` names breaks the pin: point it at a commit that stays (the task's base).
