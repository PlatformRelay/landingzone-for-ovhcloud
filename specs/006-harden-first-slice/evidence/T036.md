## Learnings

Class: guidance.
- A changelog fixture needs a subject for every group the output has, or a renderer that leaves a group empty passes; check each output key has a non-empty expected value somewhere.
- A test that runs a git-calling function in-process must unset the variables that redirect git (`GIT_DIR`, `GIT_WORK_TREE`, `GIT_INDEX_FILE`, `GIT_CONFIG_COUNT`, `GIT_CONFIG_PARAMETERS`): giving the fixture's own git a clean `cmd.Env` does not cover the code under test.
- A golden generated by a reference port is checked by a control test that builds the expected content from the fixture's own objects, so the golden is right, not merely stable.
