## Design notes (verified 2026-10-20 by reading the code)

- `stacks` cannot import `live` (`live` imports `stacks`), so the scratch-home helper stays in `live` and the caller hands the home in, as `live.Command` does for FR-007. `cmd/lz-live` reuses the exported `live.ScratchHome` (the locked-recovery seam's pattern, `recovery_tofu.go`).
- Order change: `pinnedTofu` now runs `live.ScratchOutside(checkout)` before the probe, so a TMPDIR inside the checkout is refused (exit 3, `scratch`) before the version is read; before, the version check ran first and the verbs refused TMPDIR after it. Both refusals are credential-free; a wrong tofu and a TMPDIR inside the checkout at once now report the TMPDIR first. Existing `TestTofuEntry*`, `TestLaneEntryScratchInsideCheckout` and `TestProbeScratchOutsideCheckout` stay green.
- `stacks.PinnedTofu` is outside the task's lz-live wording but shares `ResolveTofu`; it gets a private home too, so no caller of the probe uses `os.TempDir()` (the lz-stacks path runs inside the offline entry; behaviour otherwise unchanged).
- Every existing `ObserveCanary` path stores the mode explicitly before the trap is registered (`trapRemove` after a 404 read, `trapReport` after a present read, `trapNone` after a 409 create), so their behaviour is unchanged; only an unset or unknown value changes, from delete (unset) or nothing (unknown) to report.
