## Learnings

Class: guidance.
- A repository-level red the task attributes to a rule must come from the check under test, not from the test's own file probe: assert the check's finding while the precondition is missing, then fail on the precondition; and pin the same refusal on a fixture (no configuration at all), or a check silent on a missing file passes once the file exists.
- A provenance record beside a captured artefact is pinned by its content (the artefact's version and digest), not only by presence; give the base fixture's record every field the recorder writes, or the positive control steers the implementation away from checking them.
- A whole-tree pin or lock walk meets fixture pin files (`tests/**`, `**/fixtures/**`): state in the stub's contract which trees are never sources before the implementation task picks a walk.
- `sleep` is refused in a foreground command, so an `until … sleep` wait there spins and returns at once; wait in a background job, and give completion markers task-unique names (a shared scratch directory kept a stale `final.done` from another session).
