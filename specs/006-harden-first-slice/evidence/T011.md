## What changed

- `API.do` (`binding.go:73`): every error is a `*callError` naming the call and the class: `answered <code>` (status path, text unchanged), `answered 3xx` (a transport error after a recorded 3xx answer: Go parses a 3xx's `Location` before `CheckRedirect` and returns no response when that fails, `net/http/client.go`, Go 1.27.1, read 2026-10-15, verified), `quiet`'s `timed out` / `cancelled` / `request failed` (other transport errors; `Client.Do` documents its errors as `*url.Error`), `answered 200 with a body that does not decode`. No `%w` of a transport or decode error is left.
- `token()` and `account()` (rounds 1, 2): a request that cannot be built, a missing token and a missing account id are `callError`s too (`answered 200 without …`). `Bind`'s account-mismatch refusal (`binding.go:182`) names the bound id only, never the answered one.
- `API.Account` (`binding.go:130`): appends `bindNext` = `check the API endpoint, the network and the credential, then re-run` to every failure. `Bind`, `lz-live probe` (`probe.go:156`) and `lz-live lane` (`lane.go:56`) all reach the binding client through it.
- `quietToken` (`leftovers.go:173`): passes a `*callError` through (it used to match a `*url.Error` and the exact `token endpoint answered <code>` text); anything else stays `no usable token in the answer`. Without this the leftover and bearer clients would have lost the transport class (`timed out`), since `token()` no longer returns a `*url.Error`. `newBearer`'s 400/401 check (`ovhapi.go:91`) reads `token endpoint answered %d`, whose text is unchanged.
- Reading of "status class" (from T005): `3xx` where only the class is known; the full code where Go returns the answer (`302`, `401`, `200`), which names the class too. Believed; for review.
- Reading of "next action": one generic action for every class. A per-class action (credential for 4xx, endpoint for 3xx) would be sharper; not done, FR-003 asks for one and the task names no wording. Believed; for review.

## Learnings

Class: guidance.
- A field the answer chose is a body quote too: a refusal that echoes an answered id (the account) carries whatever the endpoint puts there. Do not bound the field; stop quoting it.
- A quieter error type changes what downstream classifiers see: `quietToken` matched `*url.Error`, so routing `do` through `quiet` silently dropped the leftover client's transport class until it passed the new type through. Grep every `errors.As` and text match on an error before changing its type.
- A header-quoting mutant on the status path survives tests that use only an unparseable `Location` (that path never returns a response); a parseable-redirect row is needed to kill it.
