## Learnings

Class: guidance.
- A judge must run before any earlier check that can refuse the same input in another way; otherwise that check decides the error's text and its class (here: a plain error kept the root on `--cleanup`).
- Moving a check ahead of a quoting one exposes raw input in messages: quote a refused name that holds a non-printable rune.
