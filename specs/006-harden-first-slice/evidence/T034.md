## Design

- **Command line.** `lz-pack -bundle <dir> -manifest-sha <hex> [-bwrap <file>] -out <new-dir> -commit <sha>`; `-commit` is required (usage error, exit 2, nothing written, as T031 reading 7 fixes). `main` calls `attestedPack`.
- **`attestedPack`** checks the commit's form (full lowercase 40- or 64-hex object id) before `pack` writes anything, runs `pack`, then writes the statement. A statement that cannot be rendered or written removes the layout `pack` created (the same removal `pack` applies to its own failures), so no image stands without its statement (T031's deferral, reading 9). `pack` keeps its signature (T031's and earlier tests call it with four arguments) and its contract; the statement wraps it rather than sitting inside it, because putting it inside would change `pack`'s signature and so edit fixed tests for no behaviour.
- **`pack` split** (was cognitive complexity 19): `admitPack` (paths, admission, plan, output outside the bundle), `writeLayout` (blob directory, layer, verify, index), `writeLayer`, `writeIndex`. Order of every step and every mode unchanged.
- **Statement inputs come from what was packed.** Subjects: the manifest and layer digests `pack` wrote. Entry: `verify` now returns the sha256 of `runtime/lz-offline` as extracted from the written layer (the bytes the image carries, read with `bundle.Regular`), not a second read of the input. Resources: `manifestSHA`, which `bundle.Admit` has just required the packed `resources.json` to hash to (`tools/internal/bundle/bundle.go:159`).
- **Statement** (`provenance`): in-toto Statement v1, `predicateType` `https://slsa.dev/provenance/v1`; subjects `manifest` and `layer` with `{"sha256": <hex>}`; `buildType` `<repo>/tools/cmd/lz-pack/build-type/v1`; `externalParameters.source` = `{uri: "git+<repo>", digest: {gitCommit: <commit>}}`; `resolvedDependencies` `resources.json` and `runtime/lz-offline`; `runDetails.builder.id` `<repo>/tools/cmd/lz-pack@<version>`. Rendered from maps with `encoding/json`, which writes map keys sorted (Go `encoding/json` docs: "The map keys are sorted"); no time anywhere. Input forms are T031's readings: manifest/layer `sha256:<64 hex>`, resources/entry bare 64 hex, builder `lz-pack@<version>` with a non-empty version free of spaces and control characters.
- **Builder version** (`builderVersion`): the module version the Go toolchain stamped; for an untagged build `devel`, followed by `-<vcs.revision>` and `-modified` when the build recorded them (host probe 2026-10-18: `go version -m` on a build of this tree shows `mod … (devel)`, `vcs.revision=437f1d2…`, `vcs.modified=true`; the test binary and an entry build from the snapshot, which has no `.git`, record none and give `devel`). The two reproducibility packs use one binary, so the id is the same in both.
- **Mode.** `provenance.json` is written `O_CREATE|O_EXCL`, mode 0600 (no world-readable mode in new code). The existing layout files keep their 0644/0755 modes; changing them is outside this task.
- In-toto `gitCommit` as the digest key for the commit: believed (in-toto attestation spec v1, `digest_set.md`, lists `gitCommit`); not checked against a local copy.
