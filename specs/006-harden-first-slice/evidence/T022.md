## Learnings

Class: guidance.
- A deadline that only reaches the tofu children is not the run's: give the harness a seam that reads the context a real call carries (the API transport's request context) and run it without the test's own timeout, or a zero deadline left unbounded passes.
- A wrapper that marks a run failed when its context ended must check the context, not only the error: a step that ignores the context (the S3 store) can finish after the deadline with no error.
- `apply_complete` is every completed action, not every created resource: OpenTofu 1.13.0 reports update and delete too (delete without `id_value`); an inventory of created ids filters on `hook.action`. Check event semantics against a capture from the pinned tool before reusing a consumer outside the context it was written for.
