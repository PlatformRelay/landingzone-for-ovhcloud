## Learnings

Class: guidance.
- "Appended as each event arrives" needs a read while the child still runs, bounded so it ends before the run's deadline; a read after the run passes a run that buffers until the child exits.
- A deadline test bounds when the run stopped (both sides), timed around the run call alone, not the harness's snapshots and judge; checking the signal alone passes a late stop.
- A recorded deadline is not an enforced one: a default that is a long constant needs a seam (a resolver or the context's deadline) to be testable; ask for one in the plan's fixed signatures.
