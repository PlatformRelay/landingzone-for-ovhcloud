## Task text (tasks.md)

T027 [US4] Write unreconciled-row and stage-lock tests in tools/internal/stacks/generate_test.go. Requirements: FR-011; ADRs: 0007, 0011. Depends on: none. Cases (given / when / then → defect exposed): (1) given a manifest row without a reconciled stack / when `Generate` runs / then `*GenerateError{Code: "UNRECONCILED_ROW"}` and nothing written → exposes half-generated trees. (2) given a reconcile that creates a stack / when `Generate` runs / then the stack carries its stage's `.terraform.lock.hcl` → exposes a stack without a lock. (3) given two stages whose locks pin different `ovh/ovh` versions or hashes / when `CheckStageLocks` runs / then a `STAGE_LOCK_MISMATCH` finding names both → exposes racing plugin caches. (4) given the sandbox manifest / then all green and `TestRepositoryStackLocksMatchStages` unchanged → exposes a fix that breaks the real tree. Verify: `task test:stacks`: the first three cases fail against the stubs. Evidence: `evidence/T027.md`; PR; initial status `not-run`.

## Learnings

Class: guidance.
- A "nothing written" check compares every file of the root, path and content, before and after the call: a helper that skips metadata (`stack.tm.hcl`) lets a step that writes through another writer (a real reconcile) pass. Where several rows are wrong at once and the requirement fixes no order, accept any of them.
- A lock-copy test needs per-stage locks that differ byte for byte, or a copy from the wrong stage passes.
