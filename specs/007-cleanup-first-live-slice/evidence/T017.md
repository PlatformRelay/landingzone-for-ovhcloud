## Learnings

- class: sensor. A package-level helper in a new test file can collide with one in a build-tagged test file of the same package (`adapter_test.go`, `offlinetools`): `go vet` and the default target never compile it, only `test:exchange` does. Run `go vet -tags offlinetools` on the package, or prefix new helpers with the file's subject. Recorded in loop.md *Lessons*.
- class: sensor. An order check built on a position map needs a membership check besides the counts: a missing id's index defaults to 0 and passes "after" checks. Recorded in loop.md *Lessons*.
