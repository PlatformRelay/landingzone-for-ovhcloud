## Learnings

Class: sensor.
- The repository's complexity gate (`TestComplexityRealTree` in `test:traceability`, limit 14) counts test functions, `t.Run` closures included: write table tests with a named row function from the start, and run `test:traceability` in the fast check before review.
- An HTTP client that classes failures for a retry must keep the status it saw on every failure path (body broke off, body over the bound, redirect Go cannot parse): one path without it turns a 5xx into a permanent error or a 4xx into a retried transport failure.
- A context-carried helper shared by two consumers (the Sweep and the check) must be reported by the second even when its own work cannot start (no lister), or the first one's record is lost.
