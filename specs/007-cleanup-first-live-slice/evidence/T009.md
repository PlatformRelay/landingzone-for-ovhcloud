## Design

- **Judged refs**: `spec.state.project.ref` and every tenant environment's ref (data-model). A ref the bound account does not resolve (no `LZ_PROJECT_ID_<REF>`) is skipped: it is no project, and the binding that needs it refuses it as `unbound-project` (`adapter.go` `Binding`). Refs the manifest does not use are never read.
- **Pairs**: sorted refs, every pair on one id refused unless admitted; the first refused pair in ref order is named (deterministic). Admitted (`aliasAdmitted`): the flag is set, one of the two is the state ref, and no tenant environment owns the state ref itself (T001's *Consequence*: a tenant on `STATE` would put two tenant environments on one project).
- **Detail**: data-model's text, `project refs <A> and <B> resolve to one project in account.env; give each its own project or drop one row`: refs only, no id, no path.
- **Lane**: `boundUnaliased(m, acc)` replaces the `BoundAccountFromEnv(acc)` call in `runLane` (`apply.go:259`), after the account binding and before `destroyOne`, `acted`, the chain and every lock or child. Replacing the call keeps `runLane`'s complexity unchanged (T007 lesson). The `*stacks.RefusalError` becomes `refuse(CondProjectAlias, Detail)` (exit 3).
- **Bootstrap**: `(*stateRun).setup` calls it after the state ref's check (so an `account.env` without `LZ_PROJECT_ID_STATE` keeps its message), before the region, bucket, token and every `tofu` child. `bindingFailed` reports a `*Refusal` through `r.refuse` (state phase `fail`, exit 3, redacted) and any other error (a malformed `account.env`, which `publish` already refused later) through `r.fail`. Fail-closed: such an `account.env` now stops before `state` instead of at `publish`.
